# Security policy

## Supported version

Security fixes are applied to the current default branch. Slate is a self-hosted prototype; older commits and public shared deployments are not supported releases.

## Reporting a vulnerability

Please do not publish exploit details in a GitHub issue. Use GitHub's **Report a vulnerability** option on the Security tab when it is available. If it is unavailable, open a non-sensitive issue asking the maintainer for a private contact channel, without including the vulnerability details.

Include the affected API or database path, the impact, and a minimal reproduction. Do not access data that is not yours, consume another person's provider quota, or test against third-party systems without permission.
